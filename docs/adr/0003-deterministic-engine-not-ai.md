# ADR 0003: Deterministic Rule Engine Instead of Generative AI

## Status
Accepted

## Context
The checklist generation could theoretically use an LLM, but V1 scope
explicitly excludes generative AI (spec section 3.3).

## Decision
Packing suggestions are generated by a local, deterministic rule engine
(PackingRule interface + aggregator). Same input always produces the
same output. No remote AI API is used for list generation.

## Consequences
- Rules must be isolated, testable, and independent of the UI layer.
- Store listing/marketing must not claim AI-based generation for V1.
